쉽배송 자동화 테스트 리포트

실행 일시: 2025-12-08

전체 시나리오 영상

테스트 스크린샷 링크

01. 메인 페이지

단계 : 웹사이트 진입 > 팝업 노출될 경우 [다시 보지 않기] 선택
예상 결과 : 메인페이지 이동 후 팝업이 있을 경우 닫기 동작 된다.
🔗 이미지 보기

02. 이용안내 페이지

단계 : 메인화면 > 상단 [이용안내] 버튼
예상 결과 : 신청방법, 배송비 계산, 배송금지 물품 등이 존재하는 웹페이지로 이동 및 노출된다.
링크: staging.shipbaesong.com/info
🔗 이미지 보기

03. 배송신청 페이지

단계 : 메인페이지 > 배송신청
예상 결과 : 해외배송, 구매대행을 선택할 수 있는 배송신청 메인 페이지로 이동 및 노출된다.
링크: staging.shipbaesong.com/request/main
🔗 이미지 보기

04. 배송현황

단계 : 메인페이지 > 배송현황
예상 결과 : 로그인을 하지 않았으므로 로그인 유도 화면으로 이동 및 노출된다.
🔗 이미지 보기

05. 고객지원 페이지

단계 : 메인페이지 > 고객지원
예상 결과 : 고객지원 메인페이지로 이동 및 노출된다.
링크: staging.shipbaesong.com/support
🔗 이미지 보기

06. 로그인 후 배송현황

단계 : 메인페이지 > 배송현황 > 로그인 > 배송현황
예상 결과 : 배송신청이 없는 유저의 이력이므로 "최근 신청한 내역이 없어요" 문구가 노출되며 배송신청을 유도하는 버튼이 제공된다.
🔗 이미지 보기

07. 마이페이지

단계 : 로그인 상태 > 메인페이지 > 마이페이지 진입
예상 결과 : 로그인 한 유저의 이름과 보유 포인트, 최근 신청내역과 주소록 관리 버튼이 제공된다. 배송신청을 하지 않은 유저는 "최근 신청한 내역이 없어요" 문구가 노출되며 배송신청을 유도하는 버튼이 제공된다.
🔗 이미지 보기

08. 로그아웃 완료

단계 : 로그인 상태 > 마이페이지 > 로그아웃 > 팝업 노출 시 로그아웃
예상 결과 : 로그아웃 처리가 완료된 상태로 메인페이지가 노출된다.
