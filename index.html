쉽배송 자동화 테스트 리포트

Session A – 기본 플로우

비로그인 → 로그인 → 마이페이지 → 로그아웃

01. 메인 페이지

단계: 팝업 노출 시 [오늘 그만 보기] 클릭

예상 결과: 메인 페이지 정상 노출 및 팝업 닫힘

[스크린샷 보기]

02. 마이페이지

단계: 로그인 후 마이페이지 진입

예상 결과: 사용자 정보 및 주소록 관리 버튼 확인

[스크린샷 보기]

03. 로그아웃 완료

단계: 마이페이지 → 로그아웃

예상 결과: 로그아웃 후 메인 화면으로 복귀

[스크린샷 보기]

Session B – 배송신청 및 배송현황

배송신청 → 완료 → 배송현황 → 상세보기 → 스크롤 → 캡처

01. 배송신청 완료

단계: 배송신청 입력 완료 후 ‘배송신청 완료’ 버튼 클릭

예상 결과: 완료 페이지 노출 및 완료 문구 표시

[스크린샷 보기]

02. 배송현황 상세보기

단계: ‘배송현황 보러가기’ → 상세보기 아이콘 클릭

예상 결과: 배송현황 상세 페이지 이동

[스크린샷 보기]

03. 상세 스크롤 캡처

단계: 상세 페이지 전체 스크롤

예상 결과: 화면 하단까지 정상 스크롤 및 렌더링 확인

[스크린샷 보기]
