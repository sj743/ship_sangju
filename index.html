쉽배송 자동화 테스트 리포트

테스트 진행 영상

쉽배송 서비스 자동화 테스트 전체 진행 영상입니다.
테스트는 Session A(비로그인→로그인→마이페이지→로그아웃)과 Session B(배송신청→배송현황→상세보기)로 구성되어 있습니다.

테스트 결과 요약

성공 항목: 11
실패 항목: 0

총 11개 테스트 중 100% 성공

※ 화면별 스크린샷은 실패 발생 시 자동 캡처되며, 리포트에는 전체 영상만 표시됩니다.

Session A – 기본 플로우

비로그인 → 이용안내 → 배송신청 → 배송현황(로그인유도) → 고객지원 → 로그인 → 마이페이지 → 로그아웃

01. 메인 페이지

단계: 팝업 노출 시 [오늘 그만 보기] 클릭

예상 결과: 메인 페이지 정상 진입 및 팝업 닫힘

02. 이용안내 페이지

단계: 상단 메뉴 [이용안내] 클릭

예상 결과: 신청방법, 배송비 안내 등 내용이 표시된 안내 페이지 이동

03. 배송신청 페이지

단계: 메인 > [배송신청] 클릭

예상 결과: 배송신청 메인 페이지 이동 확인

04. 배송현황 (로그인 유도)

단계: [배송현황] 클릭

예상 결과: 비로그인 상태로 로그인 유도 페이지로 이동

05. 고객지원 페이지

단계: [고객지원] 클릭

예상 결과: 고객지원 메인 페이지 노출

06. 로그인 후 배송현황

단계: 로그인 후 [배송현황] 클릭

예상 결과: “최근 신청한 내역이 없어요” 문구 확인

07. 마이페이지 진입

단계: 로그인 상태 > [마이페이지]

예상 결과: 회원 정보 및 주소록 관리 메뉴 노출

08. 로그아웃 완료

단계: [로그아웃] 버튼 클릭

예상 결과: 로그아웃 완료 후 메인 페이지로 복귀

Session B – 배송신청 및 배송현황

배송신청 → 완료 → 배송현황 → 상세보기 → 스크롤 확인

01. 배송신청 프로세스 및 완료

단계: 로그인 후 [배송신청] → 주소 → 반송지 → 수취인 입력 → 금지품목 안내 확인 → [배송신청 완료]

예상 결과: 모든 단계 정상 전환 후 신청 완료 페이지 이동 및 [배송현황 보러가기] 노출

02. 배송현황 및 상세보기

단계: [배송현황 보러가기] → 상세보기 → 상/하 스크롤

예상 결과: 상세페이지 정상 로드 및 스크롤 이동 확인
